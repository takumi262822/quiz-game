# コーディング規約

> プロジェクト: **quiz-game（クイズゲーム）**  
> 作成者: Takumi Harada  
> 作成日: 2026/04/06  

---

## 1. 概要

本ドキュメントは quiz-game における JavaScript のコーディング規約を定めます。  
全ファイルはこの規約に沿って実装・レビューすることを原則とします。

---

## 2. フォルダ構成

```
quiz-app/
├── index.html                          # ポータル画面（難易度選択）
└── src/
    ├── main.js                         # PortalManager（秘密ゲート・CPA 解放）
    ├── constants/
    │   ├── definitions.js              # コード定義（ライフライン・難易度識別子等）
    │   ├── quiz-constants.js           # ゲーム定数（出題数・遅延時間・報酬額等）
    │   ├── quiz-data.js                # 出題データのロードエントリ
    │   └── data/
    │       ├── beginner-data.js        # 初級問題データ
    │       ├── normal-data.js          # 中級問題データ
    │       ├── elite-data.js           # 上級問題データ
    │       └── cpa-data.js             # CPA 専用問題データ
    ├── core/
    │   └── quiz-engine.js              # QuizManager / CPAQuizManager（進行・判定）
    ├── entry/
    │   ├── beginner.js                 # 初級ステージのエントリーポイント
    │   ├── normal.js                   # 中級ステージのエントリーポイント
    │   ├── elite.js                    # 上級ステージのエントリーポイント
    │   └── cpa.js                      # CPA ステージのエントリーポイント
    ├── styles/
    │   └── style-manager.js            # 動的スタイル適用ユーティリティ
    ├── ui/
    │   ├── components.js               # 選択肢ボタン・報酬リスト等の DOM 生成
    │   ├── header.js                   # ヘッダー HTML 生成
    │   └── footer.js                   # フッター HTML 生成
    └── utils/
        ├── validator.js                # クイズデータのバリデーション
        └── xss.js                      # XSS 対策（エスケープ・安全な DOM 操作）
```

### 各ディレクトリの責務

| ディレクトリ | 責務 |
|---|---|
| `constants/` | 変更しないゲーム定数・問題データのみを置く |
| `core/` | 問題進行・回答判定・ライフライン管理 |
| `entry/` | 各難易度の初期化処理のみ。ロジックを含めない |
| `styles/` | 動的スタイル操作のみ |
| `ui/` | DOM 生成・描画のみ。ロジックを含めない |
| `utils/` | バリデーション・セキュリティなどの純粋関数 |

## 3. 命名規則

### 3-1. ファイル名

- **kebab-case** を使用する

```
quiz-engine.js   ✅
quizEngine.js    ❌
```

### 3-2. クラス名

- **PascalCase** を使用する

```js
export class QuizManager { }       ✅
export class CPAQuizManager { }    ✅
export class PortalManager { }     ✅
```

### 3-3. 関数・メソッド・変数名

- **camelCase** を使用する

```js
useLife(type) { }     ✅
use_life(type) { }    ❌
```

### 3-4. 定数名

- **UPPER_SNAKE_CASE** を使用する
- ゲーム定数は `constants/quiz-constants.js`、コード定義は `constants/definitions.js` に集約する

```js
export const GameConstants = {
  QUESTION_COUNT: 10,
  STANDARD_DELAY: 800,
};
```

## 5. コメント規約

### 5-1. ファイルヘッダー

全ファイルの先頭に JSDoc ブロックコメントを記述する。

```js
/**
 * <ファイルの役割を一行で>
 * @author Takumi Harada
 * @date YYYY-MM-DD
 */
```

### 5-2. メソッド区切りコメント

メソッドの手前にセクションコメントを付ける。

```js
// --- 回答ボタンのクリックを処理し、正誤判定を行う ---
check(btn, index) {
    ...
}
```

### 5-3. if 文コメント

**すべての `if` 文の直前行**に、何を判定しているかを日本語で説明するコメントを付ける。

```js
// 判定待機中は再クリックを無視して二重回答を防ぐ
if (this.isWait) return;
```

### 5-4. ライフライン分岐コメント

ライフラインの種別分岐には各ケースの意図を補足する。

```js
// ラインフラインの種別によって処理を分岐する（50:50は選択肢除外、他はモーダル表示）
if (type === GameDefinitions.LIFELINES.FIFTY) {
    ...
} else if (type === GameDefinitions.LIFELINES.TEL) {
    ...
}
```

## 6. モジュール設計

### 6-1. ES Modules 使用

`import` / `export` を使用する。`require()` は使用しない。

```js
import { GameConstants } from '../constants/quiz-constants.js';
export class QuizManager { }
```

### 6-2. 名前付きエクスポートを原則とする

```js
export class QuizManager { }          ✅
export default class QuizManager { }  ❌
```

### 6-3. import パス

拡張子 `.js` を明示する。

## 7. クラス設計

### 7-1. 難易度別クラス設計

| クラス | 対象難易度 | 使用定数 |
|---|---|---|
| `QuizManager` | 初級・中級・上級 | `STANDARD_REWARDS`, `STANDARD_DELAY`, `LOSE_DELAY` |
| `CPAQuizManager` | CPA 専用 | `CPA_REWARDS`, `CPA_DELAY`, `CPA_LOSE_DELAY` |

### 7-2. isWait フラグ

回答受付中か否かを `isWait` フラグで管理し、二重回答を防ぐ。

```js
check(btn, index) {
    // 判定待機中は再クリックを無視して二重回答を防ぐ
    if (this.isWait) return;
    this.isWait = true;
    ...
}
```

## 8. セキュリティ

### 8-1. XSS 対策

```js
import { XSSProtection } from '../utils/xss.js';

// ✅ 正しい使用
element.textContent = XSSProtection.escapeHTML(userInput);

// ❌ 禁止
element.innerHTML = userInput;
```

### 8-2. 安全な DOM 操作

`utils/xss.js` の `safeSetText()` / `safeSetHTML()` / `isSafeURL()` を積極的に活用する。

---

## 9. バリデーション

### 9-1. クイズデータのバリデーション

問題データは `Validator.isValidQuizData()` と `Validator.isValidQuestion()` で検証してから使用する。

```js
// 問題データが無効な場合はエラーメッセージを表示して処理を中断する
if (!Validator.isValidQuizData(this.allData)) {
    this.elBox.textContent = 'データがありません';
    return;
}
```
