== 概要

本書はクイズゲームで全クラス・モジュールから横断的に利用する共通処理を定義する。 +
DOM 反映前は必ず XSSProtection を経由し、入力値は Validator で検証してから利用する。

---

== 1. XSS サニタイズ処理

ファイル: `src/utils/xss.js` +
クラス: `XSSProtection`

[cols="2,2,4", options="header"]
|===
|メソッド名|引数 → 戻り値|処理内容

|`escapeHTML(str)`
|str: string → string
|`& < > " ' /` を HTML エンティティに置換する。null/非文字列は空文字を返す

|`safeSetText(el, text)`
|el: HTMLElement, text: string → boolean
|`el.textContent` に代入して XSS を防ぐ。無効な要素の場合は false を返す

|`safeSetHTML(el, html, allowedTags)`
|el: HTMLElement, html: string, allowedTags: string[] → boolean
|一時 div で解析し、script 要素と on* ハンドラを削除してから innerHTML を設定する。デフォルト許可タグ: `b i em strong br p`

|`isSafeURL(url)`
|url: string → boolean
|`http: https: mailto: tel:` プロトコルか相対パスのみ許可する

|`setSafeHref(el, href)`
|el: HTMLElement, href: string → boolean
|isSafeURL で検証後に `el.href` を設定する。不正なら false を返す

|`safeJSONParse(jsonStr)`
|jsonStr: string → object \| null
|JSON.parse をラップし、パース失敗時は null を返す

|`safeSetClass(el, className)`
|el: HTMLElement, className: string → boolean
|`el.className` に安全なクラス名を設定する
|===

.escapeHTML 変換対応表
[cols="1,1"]
|===
|入力文字|変換後
|`&`|`&amp;`
|`<`|`&lt;`
|`>`|`&gt;`
|`"`|`&quot;`
|`'`|`&#39;`
|`/`|`&#x2F;`
|===

== 2. バリデーション処理

ファイル: `src/utils/validator.js` +
クラス: `Validator`

[cols="2,2,4", options="header"]
|===
|メソッド名|引数 → 戻り値|処理内容

|`isValidLevel(level)`
|level: string → boolean
|`GameDefinitions.LEVELS` の値に含まれるか確認する

|`isValidQuizData(data)`
|data: any → boolean
|Array.isArray かつ length > 0 かを確認する

|`isValidQuestion(q)`
|q: object → boolean
|question(string)・choices(Array, 2件以上)・answer(number, 範囲内) の複合チェック
|===

== 3. ヘッダー UI 処理

ファイル: `src/ui/header.js` +
クラス: `Header`

[cols="2,2,4", options="header"]
|===
|メソッド名|引数 → 戻り値|処理内容

|`constructor(root, title)`
|root: Element, title: string → -
|ヘッダー要素とタイトル h1 を生成して内部保持する

|`setTitle(title)`
|title: string → this
|h1 テキストを更新してメソッドチェーンを返す

|`attach()`
|- → this
|`root.prepend` で DOM 先頭に挿入してメソッドチェーンを返す
|===
