== 概要

本書はクイズゲーム全体で使用する共通ユーティリティの仕様を記載します。 +
DOM 反映前は必ず XSSProtection を経由し、入力値は Validator で検証してから利用する。

---

== 1. XSSProtection クラス

=== 格納先

`src/utils/xss.js`

=== 説明

DOM への文字列反映前に HTML 特殊文字をエスケープし、XSS 攻撃を防ぐ。 +
安全な URL 検証・JSON パース・クラス名設定のラッパーメソッドも提供する。

=== 静的メソッド

==== escapeHTML(str)

[cols="2,2,4", options="header"]
|===
^.^|項目 ^.^|型 <.^|内容

<.^|引数 `str` |string |任意の値。`null` / 非文字列は空文字を返す。
<.^|戻り値 |string |`& < > " ' /` を HTML エンティティに置換した文字列
|===

.変換表
[cols="1,1", options="header"]
|===
|入力文字|変換後
|`&`|`&amp;`
|`<`|`&lt;`
|`>`|`&gt;`
|`"`|`&quot;`
|`'`|`&#39;`
|`/`|`&#x2F;`
|===

---

==== safeSetText(el, text)

[cols="2,2,4", options="header"]
|===
^.^|項目 ^.^|型 <.^|内容

<.^|引数 `el` |HTMLElement |テキストをセットする対象要素
<.^|引数 `text` |string |セットするテキスト内容
<.^|戻り値 |boolean |`el.textContent` に代入して XSS を防ぐ。無効な要素の場合は `false` を返す
|===

---

==== safeSetHTML(el, html, allowedTags)

[cols="2,2,4", options="header"]
|===
^.^|項目 ^.^|型 <.^|内容

<.^|引数 `el` |HTMLElement |HTML をセットする対象要素
<.^|引数 `html` |string |セットする HTML 文字列
<.^|引数 `allowedTags` |string[] |許可するタグ名の配列。デフォルト: `b i em strong br p`
<.^|戻り値 |boolean |一時 div で解析し、`<script>` と `on*` ハンドラを除去してから `innerHTML` に設定する。失敗時は `false`
|===

---

==== isSafeURL(url)

[cols="2,2,4", options="header"]
|===
^.^|項目 ^.^|型 <.^|内容

<.^|引数 `url` |string |検証対象の URL 文字列
<.^|戻り値 |boolean |`http:` `https:` `mailto:` `tel:` または相対パスのみ `true`
|===

---

==== setSafeHref(el, href)

[cols="2,2,4", options="header"]
|===
^.^|項目 ^.^|型 <.^|内容

<.^|引数 `el` |HTMLElement |`href` をセットする対象要素
<.^|引数 `href` |string |セットする URL 文字列
<.^|戻り値 |boolean |`isSafeURL` で検証後に `el.href` を設定する。不正な URL なら `false` を返す
|===

---

==== safeJSONParse(jsonStr)

[cols="2,2,4", options="header"]
|===
^.^|項目 ^.^|型 <.^|内容

<.^|引数 `jsonStr` |string |パース対象の JSON 文字列
<.^|戻り値 |object\|null |`JSON.parse` をラップし、パース失敗時は `null` を返す
|===

---

==== safeSetClass(el, className)

[cols="2,2,4", options="header"]
|===
^.^|項目 ^.^|型 <.^|内容

<.^|引数 `el` |HTMLElement |クラス名をセットする対象要素
<.^|引数 `className` |string |セットするクラス名
<.^|戻り値 |boolean |`el.className` に安全なクラス名を設定する。失敗時は `false`
|===
