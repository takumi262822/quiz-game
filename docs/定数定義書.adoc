== 概要

本書はプロジェクト「{project}」で利用する定数値を列挙したものです。
ソースファイル `quiz-app/src/constants/quiz-constants.js` から逆引きで抽出しています。

---

== 出題数

[cols="2,1,2,4", options="header"]
|===
|定数名
|型
|値
|内容

|QUESTION_COUNT
|number
|10
|1 ゲームで出題する問題数

|===

---

== タイミング制御（ミリ秒）

[cols="2,1,2,4", options="header"]
|===
|定数名
|型
|値
|内容

|STANDARD_DELAY
|number
|1800
|通常モードで正誤判定を見せる待機時間 (ms)

|CORRECT_DELAY
|number
|1200
|正解後に次の問題へ遷移するまでの待機時間 (ms)

|LOSE_DELAY
|number
|800
|不正解後にゲームオーバー画面へ遷移するまでの待機時間 (ms)

|CPA_DELAY
|number
|2500
|CPA モードで正誤判定を見せる待機時間 (ms)

|CPA_LOSE_DELAY
|number
|1000
|CPA モードで不正解後の遷移待機時間 (ms)

|===

---

== 秘密ゲート（CPA 解放）

[cols="2,1,2,4", options="header"]
|===
|定数名
|型
|値
|内容

|SECRET_CLICKS
|number
|6
|CPA 解放に必要なタイトルロゴのクリック数

|RUMBLE_THRESHOLD
|number
|4
|振動エフェクトが開始されるクリック数

|RESET_TIMEOUT
|number
|1200
|クリック累積がリセットされるまでの待機時間 (ms)

|UNLOCK_DELAY
|number
|200
|解放ダイアログを表示するまでの遅延 (ms)

|===
